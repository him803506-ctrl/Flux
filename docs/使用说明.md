# Flux

**自动识别文件真实格式，自动匹配密码，用 7-Zip 安全、快速地完成解压。**

---

## 一句话介绍

有些压缩包被人为改了扩展名，看起来是视频文件（`游戏资源.mp4`），实际内容是 ZIP/RAR/7Z。
更有一种网盘绕审核的分发手法：文件**前半段是真视频**，ZIP 数据整个**拼在文件尾部**。
传统做法要手动改名再解压。Flux 直接读文件头 + 文件尾识别真实格式，**不需要改扩展名**，一键解压。

```
拖入 游戏资源.mp4
  ↓
读取 File Signature（文件头魔数）
  ↓
头部判为视频？再扫文件尾，找附加的压缩包
  ↓
识别为 ZIP，发现扩展名伪装 / 尾部附加
  ↓
自动匹配密码库（若加密）
  ↓
调用 7-Zip 解压
  ↓
完成
```

---

## 核心特性

| 特性 | 说明 |
|------|------|
| **真实格式识别** | 读取文件头魔数判定，绝不依赖扩展名 |
| **伪装压缩包检测** | `xxx.mp4` 实为 ZIP → 明确提示并可直接解压 |
| **尾部附加压缩包检测** | 前半段真视频 + 尾部拼接 ZIP/7Z/RAR（网盘绕审核常见）→ 照样识别并解压 |
| **真实视频保护** | 确认为真视频（尾部无压缩包）则完全不动，不解压、不重命名 |
| **7-Zip 核心引擎** | 不自己实现解压算法；自动探测 7-Zip 路径（不写死） |
| **密码库** | 支持任意数量密码，DPAPI 加密存储 |
| **自动密码匹配** | 遇到加密包自动遍历密码库，找到即解压 |
| **批量处理** | 一次拖入多个文件，单文件失败不影响整批 |
| **实时进度 + 取消** | 进度条 + 已处理/总字节；随时可取消 |
| **安全解压** | Zip Slip / Path Traversal 防护，恶意路径直接拦截 |
| **Windows 右键菜单** | 可选开启「使用 Flux 解压」 |
| **完全本地** | 不上传文件、不上传密码、不联网、不收集数据 |

## 系统要求

- Windows 10 / 11（x64）
- **7-Zip**（必需）：从 https://www.7-zip.org/ 下载安装
  - 支持 21.07 及以上版本；开发与测试使用 26.03
  - Flux 会自动探测安装路径，**不要把路径写死**

> 分发的 `Flux.exe` 是**自包含**版本，已内置 .NET 运行时，**无需另装 .NET**。

## 快速开始

1. 安装 7-Zip
2. 运行 `Flux.exe`
3. 把文件（或文件夹）拖进窗口
4. 查看检测结果：
   - `📦 游戏资源.mp4` — 扩展名 MP4，实际格式 ZIP，状态：检测到伪装压缩包
   - `🎬 real.mp4` — 普通视频文件，无需处理
5. 点击「一键解压」，或者直接等自动处理完成

## 支持的格式

**压缩格式（可解压）**
ZIP · RAR · 7Z · TAR · GZIP · BZIP2 · XZ

**视频格式（识别后跳过处理）**
MP4 · MKV · AVI · MOV · WEBM

> 架构上 `FileTypeDetector` 与 `IArchiveEngine` 均为可扩展设计，新增格式不影响其他模块。

## 密码功能

### 密码库

- 保存任意数量密码，每条含：名称 / 密码 / 备注 / 创建时间 / 最后使用时间
- 支持添加、编辑、删除、搜索、显示、复制

### 自动匹配

遇到加密压缩包时：

1. 先试「本次任务记住的密码」
2. 再按策略遍历密码库（**最近使用优先** 或 **密码库顺序**）
3. 匹配成功 → 自动解压，用户无需输入
4. 全部失败 → 弹出输入框，手动输入后可选择保存到密码库

### 安全存储

- 使用 **Windows DPAPI**（`CurrentUser` 范围）加密
- 存储位置：`%LOCALAPPDATA%\Flux\vault.dat`
- 用文本编辑器打开是**密文**
- 密码**绝不**写入 `settings.json`、日志或任何明文文件

### 明确不做的事

Flux 的密码库**只用于用户自己保存过的已知密码**。不包含、也不会添加：

- 暴力破解
- 字典攻击
- 密码生成
- 无限密码尝试
- 任何绕过加密的功能

## 安全说明

### Zip Slip / Path Traversal 防护

解压**之前**会先列出压缩包内所有条目，对每条路径做规范化校验：

```
压缩包内：  ../../evil.exe
规范化后：  C:\Windows\evil.exe
判定：      不在目标目录内 → 拒绝解压并报错
```

同时拦截：绝对路径、盘符路径（`C:\...`）、UNC 路径、超长路径（>259 字符）。
解压后还会扫描符号链接，检出可能指向目标目录之外的链接。

### 其他错误处理

文件损坏 · 格式未知 · 密码错误 · 磁盘空间不足 · 权限不足 · 文件被占用 ·
输出目录冲突 · 路径过长 · 7-Zip 不存在 · 7-Zip 调用失败 —— 全部有中文提示，不崩溃。

---

## 原文件保护

- 默认**非破坏式**操作：不改名、不覆盖、不修改原始文件
- 直接把原文件作为压缩数据交给 7-Zip，或生成临时文件解压
- 「保留原始文件」默认开启；即使关闭，也是**移入回收站**而非直接删除
- 取消任务时会清理未完成的输出目录，原文件不受影响

---

## 输出目录

默认：`原文件所在目录\文件名\`

```
D:\Downloads\游戏资源.mp4
  ↓
D:\Downloads\游戏资源\
```

若目录已存在，可选：

- **创建新目录**（默认推荐）→ `游戏资源 (2)\`
- 使用已有目录
